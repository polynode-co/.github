# Contributing to Polynode projects

Thanks for helping. Each project's README explains how to run it; where a project has its own `CONTRIBUTING.md`, follow
that one.

- Open an issue first for anything bigger than a small fix, so we can agree on the approach.
- Branch from the default branch and open a pull request into it, with a description of what changes and why.
- Run the project's checks (typecheck, tests) before you push, and keep docs in step with the code.

By contributing you agree your work is licensed under the project's license (AGPL-3.0 unless the repo says otherwise).
