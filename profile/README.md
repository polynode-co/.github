# Polynode

We build AI-native software that your AI agent can run, and we're making it open source: run it yourself for free, or let us host it for you.

## Projects

| | |
|---|---|
| **[Meerko](https://meerko.ai)** | The open-source GTM agent. Your agent finds leads, finds and verifies their emails, sends sequences from your own Gmail and catches every reply, over MCP, a CLI or the dashboard. AGPL-3.0, self-hosted or on Meerko Cloud. *Source code opening soon.* |
| **[Antwork](https://antwork.io)** | An AI social media manager inside ChatGPT and Claude. Drafts start from each account's recent posts, you approve each one, and they publish to 8 platforms. |

## How we build

- **Open by default.** New projects are open source under AGPL-3.0: free to self-host, with a hosted version for teams who'd rather not run it.
- **Agent-native.** Every product works from your AI agent (Claude Code, Cursor, Codex, ChatGPT) over MCP, with a CLI and an API alongside.
- **Your data, your accounts.** Email goes out from your own mailbox, posts from your own social accounts, and nothing runs without your OK.

## Get involved
